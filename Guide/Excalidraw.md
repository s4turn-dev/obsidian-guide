## Что такое Excalidraw?

**Excalidraw** - бесплатный инструмент для создания простых эскизов и диаграмм "от руки". Он представляет собой виртуальную доску, где можно рисовать, добавлять фигуры, писать и визуализировать идеи.

>[!tip] Интересное
>Для более подробного ознакомления рекомендуем зайти на [сайт](https://plus.excalidraw.com/how-to-start) Excalidraw.

Помимо веб-версии, существует замечательный плагин для Obsidian, который так и называется - Excalidraw.

## Плагин Excalidraw

>[!warning] Внимание
> Эта статья предполагает, что ты уже знаешь [[Плагины-в-Ob8idian|как устанавливать сторонние плагины]].

**Плагин Excalidraw** - лучший помощник для конспектирования лекций. Когда на лекции нужно зарисовать сложную схему, у тебя есть три варианта развития событий:

1. Фотографировать рисунки с доски, а потом вставлять их в конспект.
2. Вставлять скриншоты из учебника, если он доступен онлайн.
3. Рисовать самостоятельно прямо в заметках с помощью Excalidraw.

Главное преимущество последнего пункта - это красота и единообразие твоего конспекта. Все твои схемы и диаграммы будут органично вписаны в конспект, и ты сможешь легко их редактировать в будущем.

## Основные возможности и горячие клавиши

###  Создание и редактирование

- `r` - выбрать инструмент "прямоугольник".
- `o` - выбрать инструмент "эллипс".
- `Enter` - после создания фигуры позволяет добавить в нее текст.
- `Tab` - во время создания или редактирования фигуры позволяет быстро переключаться между разными формами.
- `Cmd/Ctrl` + `Arrow` - создать узел для блок-схемы, соединенный с текущим.

### Навигация

- `Shift` + `1` - приблизить так, чтобы все элементы поместились на экране.
- `Cmd/Ctrl` + `F` - найти текст на текущем холсте.
- `Cmd/Ctrl` + `K` - привязать ссылку к элементу.

>[!important] Важно
>В данной статье перечислены основные возможности для создания и редактирования рисунков и схем, которые чаще всего будут встречаться. Для подробного изучения возможностей данного плагина и его горячих клавиш рекомендуем ознакомится со справкой по нажатию `?`.

## Библиотека фигур

Excalidraw поддерживает библиотеки фигур. Это наборы готовых элементов, которые можно импортировать и использовать в своих рисунках, что экономит массу времени.

Для доступа к библиотеке нажми на иконку "книжки" справа на панели инструментов.

![[Excalidraw_иконка-библиотеки.png|300]]

Откроется боковая панель, здесь ты можешь:

1. Добавить собственные нарисованные элементы в личную коллекцию.
2. Скачать и установить наборы готовых фигур от сообщества.
3. Посмотреть гайд по установке библиотек фигур.

![[Excalidraw_панель-библиотеки.png|400]]

>[!tip] Наш набор фигур

## Панель инструментов

Отличный помощник при работе с файлами из хранилища и не только. Она позволяет добавить:

1. Файл из системы.
2. Файл из хранилища Obsidian.
3. Сноску, которую можно редактировать как карточку.
4. LaTeX формулу - лучшая фича для студентов, которая позволяет писать формулу в формате LeTeX прямо на холсте.

Для доступа к панели инструментов нажми на иконку "картины" на панели сверху.
![[Excalidraw_панель_инструментов_сверху.png|300]]

## Сохранение рисунков

Стоит пояснить, что просто сохранить рисунок бывает недостаточно, иногда его нужно подредактировать, или исправить. Как раз для этого можно поступить следующим образом:

1. Выделить нарисованные объекты и нажать `Ctrl/Cmd + G` - это нужно, чтобы сгруппировать выделение (либо выделить объекты, нажать на них правой клавишой мыши и выбрать пункт "сгруппировать выделение").
2. Выбрать "Сохранить \[\[ссылку]] для выбранного элемента(ов)"
![[Excalidraw_ссылка_для_выбранных_элементов.png|400]]
3. Выбрать "Group".
![[Excalidraw_ссылка_на_группу.png]]

Супер! Теперь, когда нужно исправить рисунок или сделать для себя дополнительные пояснения, тебе нужно просто перейти по ссылке и автоматически откроется файл excalidraw, где ты можешь обратно разгруппировать объекты и внести правки.
